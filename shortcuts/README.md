# 📱 Shottr Web - iOS 단축어(Shortcuts) 세팅 가이드

아이폰에서 스크린샷을 찍자마자 **"공유 시트"** 또는 **"단축어 한 번 클릭"**으로 GitHub Pages에 올려둔 **Shottr Web 앱으로 쏘아보내는 방법**입니다.

---

## 🛠️ 단축어 생성 3단계 가이드

아이폰의 **[단축어]** 앱을 열고 아래 순서대로 동작(Action)을 추가하세요.

### 1단계: 단축어 기본 설정
* **단축어 이름**: `Shottr Web 캡처`
* **공유 시트 설정**: 단축어 상세 설정에서 **"공유 시트에 표시"** 켜기
* **받는 유형**: `이미지` 선택

### 2단계: 동작(Action) 블록 추가

1. **[입력 가져오기]**:
   - `[단축어 입력]` 받기 (공유 시트에서 이미지가 들어온 경우)
   - 만약 입력이 없다면 ➔ `[최신 스크린샷 3장 가져오기]` 선택

2. **[웹페이지 열기 (Safari)]**:
   - URL: `https://<본인-github-username>.github.io/shottr-web-pwa/`
   - *팁: PWA로 아이폰 홈 화면에 추가해 둔 경우, 웹앱을 바로 띄우면 1초 만에 로드됩니다.*

---

## 🚀 사용법 (UX Workflow)

1. 아이폰에서 길게 캡처하고 싶은 카톡/웹페이지 화면을 **연속 스크린샷 2~3장** 찰칵 찍습니다.
2. 스크린샷 섬네일을 누르거나 [사진] 앱에서 방금 찍은 사진들을 선택 후 **[공유]** 버튼을 누릅니다.
3. 목록에서 **[Shottr Web 캡처]** 단축어를 누르면 웹앱이 열립니다.
4. 웹앱에서 사진이 **자동으로 긴 화면으로 합성(Stitching)**되며, 바로 화살표/모자이크/마커 주석 편집을 진행하시면 됩니다!
